# SQL Queries: ClassicModels Database

20 SQL queries against the ClassicModels sample database (customers, orders, payments, employees, offices, products). They cover multi-table `JOIN`s, `GROUP BY` / aggregation, sub-queries, filtering and rounding.

**Context:** CSC2001F Databases module, UCT (2024). Individual.

Run a query in MySQL with the ClassicModels schema loaded:
```bash
mysql classicmodels < query20.sql
```
