# BiofilmModeling

All commands should be run from top of folder view.
You must have Java 11 (jdk11) or later.


to run functionalPrototype use : java .\functionalPrototypeototype_0\src\SplittingBacteriaSimulation.java
once it is finished you can use : python .\functionalPrototypeototype_0\src\GifMaker.py
which will create a gif and image in .\functionalPrototypeototype_0\bin

alternatively you can compile it with javac.
Currently the program is hardcoded to only work from the root directory of this project. That being the dir that this read me is in.


The config file in /functionalPrototype can be altered and it is recomended to lower the simulation time if it is taking too long.
